# Upload instructions

Upload this whole folder into the repository as:

`reports/schism_tuflow_aligned_comparison/`

Do not replace any existing folder. The new page will then be available at:

`https://ldfpipi.github.io/spoon-estuary-schism-aed/reports/schism_tuflow_aligned_comparison/`

## GitHub web interface

1. Open the repository.
2. Open `reports`.
3. Choose **Add file → Upload files**.
4. Upload the folder contents while preserving `assets/figures`.
5. Commit directly to `main` or create a review branch.

The page uses only local HTML/CSS/images and does not alter the current GitHub Pages configuration.
