# TUFLOW FV–SCHISM Inter-Model Benchmark

This repository contains a GitHub Pages technical report for the Tutorial Module 05 Estuary benchmark.

## Publish with GitHub Pages

1. Create or open a GitHub repository.
2. Upload the complete contents of this package.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the branch (usually `main`) and the `/docs` folder.
6. Save. GitHub will display the published report URL after deployment.

The report entry page is `docs/index.html`.

## Structure

- `docs/` — GitHub Pages site
- `docs/assets/images/` — report figures
- `docs/data/` — metrics, time series and audit outputs
- `scripts/` — updated comparison scripts

## Important interpretation note

This is an inter-model verification report, not validation against observations.
