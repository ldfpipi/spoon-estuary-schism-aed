How to preview locally
----------------------
1. Open this folder.
2. Double-click index.html.

How to put on GitHub Pages
--------------------------
Option A:
- Copy index.html and the figures folder into your repository's docs/ folder.
- In GitHub repository Settings > Pages, publish from the docs/ folder.

Option B:
- If your existing GitHub Pages site already has a folder for this comparison,
  copy index.html and figures/ into that location.

Important
---------
The original uploaded figure files were not renamed or modified.
This package is a separate copy created only for the web page.


Image zoom
----------
All result figures are clickable.
- Click an image to enlarge it.
- Click the enlarged image or dark background to close.
- Click the × button or press Esc to close.
