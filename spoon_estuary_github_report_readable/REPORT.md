# TUFLOW FV-AED and SCHISM-AED comparison

The complete figure-led report is provided as a responsive GitHub Pages site:

**[Open the report](docs/index.html)**

The web report uses:

- equal-width TUFLOW and SCHISM columns;
- the same image-stage dimensions within each comparison;
- separate matched rows for TN, chlorophyll-a, dissolved oxygen, PAR and total light;
- full-resolution images that open when clicked;
- separate sections for model-specific diagnostics rather than forcing unrelated plots into one composite.

## Main diagnostic findings

1. Both models reproduce the same estuary geometry and several common along-estuary patterns.
2. TUFLOW FV-AED displays stronger vertical structure in dissolved oxygen, TSS, turbidity and nutrients.
3. The supplied SCHISM-AED fields are often close to vertically uniform despite the multi-layer grid.
4. SCHISM-AED PAR and total-light diagnostics are effectively zero and should be checked before interpreting GPP differences.
5. Current outputs are not yet a fully harmonised quantitative inter-model comparison because some timestamps, vertical extraction methods and units differ.
